# Lab Tools VS Code 拡張 — 在室 UI 仕様書

## 1. 概要

研究室在室管理サーバー（`GET /status`、`POST /start_attendance`、`POST /end_attendance`）と連携し、VS Code 上で**自分の在室状態**と**研究室全体の在室状況**を確認・操作する UI を提供する。

対象: `vscode-extension/lab-tools`

| 領域 | 役割 |
|------|------|
| サイドバー（Activity Bar → Lab Tools） | 自分の状態操作 + 学年別在室一覧 |
| ステータスバー（左・右） | 常時表示のサマリー + ショートカット操作 |
| ビューアクション | 手動リロード |

**背景:** スマホの Wi-Fi 検知による自動入退室と並行運用する。誤退室に気づけるよう、退室検知時の**音声**を重視する。

**通知方針:** 意図的な入退室のたびにトーストを出すと煩わしいため、**通知（トースト・ダイアログ）はエラー時のみ**。成功時は UI 更新と退室音のみ。

## 3. 共通データ・表示ルール

### 3.1 API

| 用途 | メソッド | パス | 認証 |
|------|----------|------|------|
| 在室ボード取得 | GET | `/status` | 不要 |
| 入室 | POST | `/start_attendance` | API キー + username/password |
| 退室 | POST | `/end_attendance` | API キー + username/password |

### 3.2 在室状態チップの配色

| `present` | 表示 | チップ色 |
|-----------|------|----------|
| `true` | 在室 | **緑** |
| `false` | 不在 | **赤** |

チップの時間フォーマット: **`{h}h{mm}`**（例: `0h12`, `2h03`）

### 3.3 時刻表示（到着・帰宅）

在室状況の行: `{名前}  {到着} - {帰宅}`  
帰宅未確定: `09:15 - `（ハイフン後は空文字）

## 4. 在室・総在室チップ（リッチデザイン）

### 4.1 共通ルール

| 項目 | 仕様 |
|------|------|
| 横幅 | **コンテンツ幅のみ**（`display: inline-flex; width: fit-content`） |
| 表記 | `在室 · 0h45` / `不在 · 2h03`（中点区切り） |
| 自分・メンバー | **同一デザイン・同一サイズ**（コンパクト版は作らない） |
| 光り方 | 外側 `box-shadow` グロー + 在室時ドット pulse（案による） |
| ステータスバー | テキスト簡略版 `在室 0h45`（グローなし） |

### 4.2 デザイン候補

詳細モックアップ: `agent-responses/2026-08-31_13-08_リッチチップ候補.html`

| 案 | 名称 | 特徴 |
|----|------|------|
| **A** | Neon Glow | ネオン管風。明るいボーダー＋強い外光。視認性最大 |
| **B** | Aurora Glass | ガラス質感＋柔らかいオーロラ光。上品 |
| **C** | Luminous Ring | 二重発光リング＋脈動ドット。コンパクトで印象的 |
| **D** | Crystal Shine | 上面ハイライト＋立体感。宝石風 |
| **E** | Soft Halo | 暗いピル＋文字発光。控えめ |

**採用: A Neon Glow（光量控えめ版）。** 在室=緑系グロー、不在=赤系グロー。自分・メンバー同一デザイン。

### 4.3 配置

```
自分の状態:
  [在室 · 0h45]        ← 左寄せ、幅はコンテンツのみ

在室状況（メンバー行）:
  田中太郎  09:15 -     [在室 · 0h45]   ← 右端に同じチップ
  ─────────────────────────────────
  佐藤花子  10:30-18:00 [不在 · 2h03]
```

## 5. 入退室ボタン

| 状態 | ラベル | 色 | 表示条件 |
|------|--------|-----|----------|
| 在室中 | 退室 | **マット赤** | 常に表示 |
| 不在中 | 入室 | **VS Code 基準色（青）** | 自動入室 OFF 時のみ |

### 5.1 ボタン配色

| ボタン | 色 | CSS 変数・値（案） |
|--------|-----|-------------------|
| 入室 | VS Code プライマリ（青） | `background: var(--vscode-button-background)` / `color: var(--vscode-button-foreground)` |
| 退室 | マット赤（基準色に馴染む） | `background: #9e4a44`（ライト）/ `#7a3b36`（ダーク）、`color: #fff` |

退室ボタンは鮮やかな赤ではなく、VS Code UI に馴染む**くすんだ赤**とする。ホバー時は明度を ±10% 程度。

### 5.2 自動入室 ON 時のボタン表示（確定）

| 自分の状態 | チップ | サイドバーボタン |
|------------|--------|------------------|
| 在室 | 緑 | **赤「退室」のみ** |
| 不在 | 赤 | **なし** + ヒント「VS Code を操作すると自動入室します」 |

手動入室のフォールバック: **ステータスバー左クリック**（確認ダイアログ付き）。

### 5.3 自動入室 OFF 時

| 自分の状態 | ボタン |
|------------|--------|
| 在室 | 赤「退室」 |
| 不在 | 青「入室」 |

### 5.4 押下時

1. 確認ダイアログ（入室:「入室しますか？」/ 退室:「退室しますか？」）
2. OK → `POST /start_attendance` または `POST /end_attendance`
3. 成功 → **reload のみ**（トーストなし）
4. 失敗 → **エラー通知**（`showErrorMessage`）

## 8. 自動更新

| 項目 | 仕様 |
|------|------|
| 間隔 | 60 秒（`labTools.pollIntervalSeconds`） |
| 動作 | `GET /status` → UI 更新 |
| 状態変化検知 | 自分の `present` が `true→false` になったとき退室音（§10） |

## 9. 自動入室

### 9.1 設定

| キー | 型 | デフォルト | 説明 |
|------|-----|------------|------|
| `labTools.autoCheckIn` | boolean | `false` | 不在時に VS Code 操作があれば自動入室 |

### 9.2 トリガー

不在かつ `autoCheckIn === true` のとき:

- ウィンドウがフォーカスを得た
- テキスト編集等の VS Code 操作

**抑制:** クールダウン 5 分、設定未完了時は実行しない。

### 9.3 自動入室成功時

- UI を reload で更新
- **通知なし**（エラー時のみ通知）

## 10. 退室時の音声

### 10.1 目的

Wi-Fi 自動退室の誤検知に気づくため。トーストは出さず**音のみ**。

### 10.2 検知タイミング

自分の `present` が **`true` → `false`** に変化したとき:

| 経路 | 検知 |
|------|------|
| VS Code から退室 | `POST /end_attendance` 成功後 |
| Wi-Fi 等の外部退室 | polling で `revision` 変化 → `present` が false に |

### 10.3 フィードバック

| 種別 | 成功時 | エラー時 |
|------|--------|----------|
| トースト・ダイアログ | **出さない** | `showErrorMessage` |
| 音声 | 退室検知時のみ（§10.2） | なし |
| UI | reload でチップ・ボタン更新 | エラー表示 |

### 10.4 音の仕様

| 項目 | 内容 |
|------|------|
| ファイル | 拡張同梱 `.wav`（0.3〜0.5 秒） |
| 設定 | `labTools.soundOnCheckOut`（default: `true`） |
| 実装 | Windows: `Media.SoundPlayer` 等 |
| 入室時 | **音なし** |
| 自動入室時 | **音なし** |

## 11. 通知ポリシー（確定）

| イベント | 通知 | 音 |
|----------|------|-----|
| 手動入室成功 | なし | なし |
| 手動退室成功 | なし | なし |
| 自動入室成功 | なし | なし |
| 退室検知（外部含む） | なし | **あり** |
| API エラー・設定未完了 | **エラー通知** | なし |

---

## 12. 設定一覧

| キー | 型 | デフォルト | 説明 |
|------|-----|------------|------|
| `labTools.autoCheckIn` | boolean | `false` | VS Code 操作で自動入室 |
| `labTools.soundOnCheckOut` | boolean | `true` | 退室検知時に音を鳴らす |
| `labTools.pollIntervalSeconds` | number | `60` | 自動更新間隔（秒） |

※ `notifyOnCheckOut` / `notifyOnAutoCheckIn` は採用しない。
